# ボートレース統計入門

Racket（通常言語）とデータフレームライブラリ **「RacketFrames」** を用いて、オープンデータ API（**`turnmark/api`**）からのデータ収集・前処理から統計データの可視化、簡易予測モデルの作成までを学ぶ、文系大学生（プログラミング・統計初心者）向けの入門電子書籍リポジトリです。

---

## 🎯 本書の対象読者
* Scratchを少し触ったことがあり、テキストベースのプログラミングに挑戦したい方。
* RやPythonの前に、シンプルかつ安全な環境（DrRacket）でデータ分析の実利を学びたい方。
* ボートレースのデータを題材に、楽しく実用的な統計学を学びたい方。

## 🛠️ 開発と検証
本書のサンプルコードおよびZenn/EPUBプレビュー環境は、タスクランナー `mise` を用いてローカル検証が可能です。

### 事前準備
```bash
# ツールのセットアップ
mise trust
mise install
npm install
```

### データ取得・パース・プロット・テスト実行
* **無確認本日データ取得**: `mise run data:download:today`
* **対話指定単日データ取得**: `mise run data:download:json`
* **対話指定過去期間一括蓄積**: `mise run data:download:range`
* **JSONパース&CSV全自動生成**: `mise run parse:json`
* **モーター相関散布図表示**: `mise run plot:scatter`
* **予想AI的中率答え合わせテスト**: `mise run model:predict`
* **全Racketスクリプト一括自動テスト**: `mise run test:racket`
* **Zennプレビュー（ローカルサーバー）**: `mise run book:preview`
