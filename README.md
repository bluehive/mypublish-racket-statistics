# ボートレース統計入門

Racket（通常言語）とデータフレームライブラリ **「RacketFrames」** を用いて、データ解析の基礎から統計データの可視化、簡易予測モデルの作成までを学ぶ、文系大学生（プログラミング・統計初心者）向けの入門書籍です。

## 🎯 本書の対象読者
* Scratchを少し触ったことがあり、テキストベースのプログラミングに挑戦したい方。
* RやPythonの前に、シンプルかつ安全な環境（DrRacket）でデータ分析の実利を学びたい方。
* ボートレースのデータを題材に、楽しく実用的な統計学を学びたい方。

## 🛠️ 開発と検証
本書のサンプルコードおよびEPUBビルドシステムは、タスクランナー `mise` を用いてローカル検証が可能です。

### 事前準備
```bash
# ツールのセットアップ
mise install
npm install
```

### プレビューとビルド
* **Zennプレビュー（ローカルサーバー）**: `mise run zenn:preview`
* **電子書籍EPUBビルド（横書き）**: `mise run book:epub`
* **電子書籍EPUBビルド（縦書き）**: `mise run book:epub-vertical`
