> **使用言語**: Racket（`#lang racket`）  

#### 1.1 ScratchからRacketへ：ブロックとテキストコードの対応

Scratch などのビジュアルプログラミングを経験した方にとって、テキスト言語は難しく見えるかもしれません。しかし、行っている**考え方の構造は全く同じ**です。

まずは Scratch の代表的なブロックと、Racket での書き方の対応を見てみましょう。

| 行いたいこと | Scratch ブロックのイメージ | Racket コード |
| :--- | :--- | :--- |
| **値の計算** | `(10) + (20)` | `(+ 10 20)` |
| **変数に値を保存** | `[勝率] を (0.75) にする` | `(define win-rate 0.75)` |
| **関数の定義** | `定義 [2倍する (x)]` | `(define (double x) (* x 2))` |
| **条件分岐** | `もし <(x) > (50)> なら...` | `(if (> x 50) "合格" "不合格")` |
| **リストの作成** | `リスト [艇番] を作成` | `(define boats '(1 2 3 4 5 6))` |

Racket では、名前の間にハイフン（`-`）を使うのが標準的なスタイルです（例： `win-rate`, `calc-score`）。

#### 1.2 基本的な計算と関数：DrRacketでの動かし方

プログラムを再利用可能な部品にするために、**「関数（function）」** を作ります。

Racket で関数を定義する基本形は次のとおりです。

```racket
#lang racket

;; 関数の定義: (define (関数名 引数1 引数2 ...) 実行する計算)
(define (calc-payout-rate total-sales total-payout)
  (/ total-payout total-sales))

;; 関数の呼び出し
(calc-payout-rate 10000 7500)  ; => 3/4 または 0.75
```

##### 複数の条件分岐：`cond` 式
「もし1号艇ならA、2号艇ならB...」のように条件が複数ある場合は、`cond` 式を使うと綺麗に書けます。

```racket
(define (get-course-color boat-number)
  (cond
    [(= boat-number 1) "白"]
    [(= boat-number 2) "黒"]
    [(= boat-number 3) "赤"]
    [(= boat-number 4) "青"]
    [(= boat-number 5) "黄"]
    [(= boat-number 6) "緑"]
    [else "不明な艇番"]))

(get-course-color 1)  ; => "白"
(get-course-color 4)  ; => "青"
```

各条件は角括弧 `[...]` で囲み、最後にどの条件にも当てはまらない場合の処理を `[else ...]` に書きます。

#### 1.3 リストとハッシュの基本：データをまとめる方法

複数のデータを扱って統計処理を行うには、データをひとまとめにする構造が必要です。Racket では主に **リスト（List）** と **ハッシュテーブル（Hash）** を使います。

##### 1. リスト（List）
同じ種類のデータ（例えば6艇の艇番や、レースの着順）を順番に並べたものです。

```racket
;; リストの作成
(define boat-numbers '(1 2 3 4 5 6))
(define racer-names '("峰" "毒島" "瓜生" "白井" "桐生" "馬場"))

;; リストの要素数を得る
(length boat-numbers)  ; => 6

;; リストの先頭要素を取得する
(first racer-names)    ; => "峰"

;; リストの2番目以降を取得する
(rest racer-names)     ; => '("毒島" "瓜生" "白井" "桐生" "馬場")
```

##### 2. ハッシュテーブル（Hash Table）
「キー（名前など）」と「値（データ）」をペアにして保存する辞書のような構造です。

```racket
(define racer-win-rates
  (hash "峰" 0.85
        "毒島" 0.81
        "白井" 0.78))

(hash-ref racer-win-rates "峰")  ; => 0.85
```

#### 1.4 【基礎知識】超わかりやすいボートレース（競艇）のルールと仕組み

これから扱うボートレースデータの背後にあるドメインルール（ドメイン知識）を直感的に理解しましょう。

##### 1. レースの基本情報
* **6艇で争う**: レースは常に **1号艇（白）〜6号艇（緑）** の6艇で行われます。
* **コース**: 1周600mの楕円形コースを **3周（合計1,800m）** 走ります。

##### 2. スタートのルール（超重要！）
ボートレースは「ヨーイドン」で止まった状態からスタートするのではなく、助走をつけてスタートラインを通過する **「フライングスタート方式」** を採用しています。

* 大時計が **0秒になった瞬間〜1秒以内** にスタートラインを通過しなければなりません。
* **0秒より早すぎる $\rightarrow$ フライング (F)**: 反則失格となり、その艇に賭けられた舟券代は全額返還（返還欠場）されます。
* **1秒より遅すぎる $\rightarrow$ 出遅れ (L)**: 失格扱いとなり、勝てる見込みがなくなります。

> **💡 なぜ1号艇（最内コース）が圧倒的に有利なのか？**  
> 最短距離でスタートラインを通過でき、第1ターンマーク（最初のコーナー）を先頭で旋回できるためです。

##### 3. コース取りのルール
* ピットアウト（待機場所から飛び出す）後、スタートまでの「待機行動」で進入コースが決まります。
* 基本は枠番通りの「枠なり進入（1号艇が1コース）」ですが、ベテラン選手（イン屋）が外枠から強引に内側のコースを奪いにいく「深イン」などの駆け引きが発生します。

##### 4. 勝敗と賭け方
* 1着〜6着まで着順が決まり、賞金も順位順に支払われます。
* **2連単**: 1着・2着の組合せを順番通り当てる。
* **3連単**: 1着・2着・3着を完全な順序で当てる（一番人気で一番難しい。**平均配当は約7,000円〜8,000円**）。

##### 5. アクシデントと天候
* レーサーが転覆・沈没してもレースは続行されます。他艇への妨害行為は減点や斡旋削除（出場停止）の厳しいペナルティとなります。
* 風向きや波の高さなどの自然条件によって、アウトコースが穴を開けるなどレース展開が大きく変化します。
