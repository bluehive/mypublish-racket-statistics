#### 3.1 そもそも「データフレーム」ってなに？

みなさんは Excel（エクセル）や Google スプレッドシートで、下のような「表」を見たことがありますよね。

```text
  【普段私たちがよく見る「表」のイメージ】

  +------+----------+----------+----------+
  | 行   | 選手名   | 全国勝率 | 艇番     |  <-- 列（項目名）
  +------+----------+----------+----------+
  | 0    | 峰竜太   |   0.85   |    1     |
  | 1    | 毒島誠   |   0.81   |    2     |
  | 2    | 瓜生正義 |   0.72   |    3     |
  +------+----------+----------+----------+
    ^
  行番号（見出し）
```

Racket の世界で、この **「縦と横に綺麗に並んだ表データ」** をそのまま扱うための仕組みが **「DataFrame（データフレーム）」** です。

Racket でデータフレームを読み込むのは、たったの 2 行で完了します。

```racket
#lang racket
(require racketframes)

;; CSVファイルを読み込んで「表（df）」を作る
(define df (read-csv "data/races.csv"))

;; 表の概要（何行・何列あるか）を画面に出す
(df-summary df)
```

#### 3.2 RacketFrames をつくる「3つの主要なパーツ」

データフレームの内部は、実は **「3つの主要パーツ」** が組み合わさってできています。

```text
+-----------------------------------------------------------------------+
|                       1. DataFrame (表全体)                           |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  |  2. Index (行の見出しタグ / 背番号)                             |  |
|  |     [ 0,  1,  2,  3,  ... ]                                     |  |
|  +-----------------------------------------------------------------+  |
|  |  3. Series (縦1列のデータグループ)                              |  |
|  |     • 列A: "racer_name" -> CSeries ["峰竜太", "毒島誠", ...]    |  |
|  |     • 列B: "win_rate"   -> NSeries [0.85, 0.81, ...]          |  |
|  |     • 列C: "boat_num"   -> ISeries [1, 2, ...]                  |  |
|  +-----------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

1. **DataFrame（データフレーム）**: 縦と横を組み合わせた「表全体」の箱。
2. **Index（インデックス）**: 各行にペタッと貼られた「行番号の見出しタグ」。
3. **Series（シリーズ）**: 縦1列に並んだ「同じ種類のデータの束（たば）」。

この 3 つが協力することで、大量のデータを間違えずに素早く計算できます。

---

#### 3.3 Series（シリーズ）は「縦1列のデータ専門チーム」

「シリーズ（Series）」とは、表の **縦1列（縦の列）** のことです。
RacketFrames では、扱うデータの種類（文字か、整数か、小数か）に合わせて、以下の **3つの主要な専門チーム** が用意されています。

```text
  【縦1列（シリーズ）の主な種類と専門分野】

    ① ISeries（整数専門）        ② NSeries（小数・数値専門）     ③ CSeries（文字・名前専門）
   +--------------------+      +--------------------+      +--------------------+
   | 艇番 (boat_num)    |      | 全国勝率 (win_rate)|      | 選手名 (racer_name)|
   +--------------------+      +--------------------+      +--------------------+
   | 1                  |      | 0.85               |      | "峰竜太"           |
   | 2                  |      | 0.81               |      | "毒島誠"           |
   | 3                  |      | 0.72               |      | "瓜生正義"         |
   +--------------------+      +--------------------+      +--------------------+
   (Fixnum = 整数の数字)        (Flonum = 小数の数字)       (Categorical = 文字列)
```

* **`ISeries` (アイ・シリーズ)**: 1, 2, 3 のような「整数の数字」専門。
* **`NSeries` (エヌ・シリーズ)**: 0.85 や 52.4 のような「小数の数字」専門。平均値などの計算が得意！
* **`CSeries` (シー・シリーズ)**: 選手名や会場名などの「文字（名前）」専門。

このように型をきっちり分けておくことで、パソコンのメモリを無駄にせず、超ハイスピードで計算できるようになります。

#### 3.4 Index（インデックス）の秘密：図書カードと自動位置合わせ

「インデックス（Index）」は、データを探すための **「見出しタグ（図書カード）」** のような役割を持っています。

```text
  【インデックスがあるから一瞬で見つかる！】

     Index (見出しタグ)            データの行
       [ 0 ] --------------> 0行目: 峰竜太 選手
       [ 1 ] --------------> 1行目: 毒島誠 選手
       [ 2 ] --------------> 2行目: 瓜生正義 選手
```

##### 秘密①: $O(1)$ の一瞬アクセス（定数時間検索）
インデックスがあるおかげで、10万行ある巨大なデータからでも、目的の行を **瞬時（0.001秒以下）** に引っ張り出すことができます。

##### 秘密②: 自動位置合わせ（アラインメント）
もし、順番がバラバラな2つの列を足し算しようとしても、インデックスが自動的に同じタグ同士をマッチングして計算してくれます。

```text
  【シリーズ A (勝率)】      【シリーズ B (ハンデ)】        【自動位置合わせ後の計算結果】
   Index   値                 Index   値                    Index   合計値
    [0]    0.85     ＋         [1]    20.0       =====>      [0]    0.85 + 40.0 = 40.85
    [1]    0.81                [0]    40.0                   [1]    0.81 + 20.0 = 20.81
  (順番が逆でも、Index [0] 同士、Index [1] 同士を自動で正しくセットにして計算！)
```

#### 3.5 データフレームのルールと注意点

データフレームを安全に扱うために、知っておくべき **「2つの大事なルール」** があります。

```text
  【ルール①: 列の長さはすべて同じ！】

    CSeries "選手名"     NSeries "全国勝率"     ISeries "艇番"
   +------------------+ +------------------+ +------------------+
   | "峰竜太"         | | 0.85             | | 1                |
   | "毒島誠"         | | 0.81             | | 2                |
   | "瓜生正義"       | | 0.72             | | 3                |
   +------------------+ +------------------+ +------------------+
   (すべて「3行」で揃っている必要がある！長さが違うとエラーになります)
```

1. **すべての列（Series）は同じ長さで揃える！**:
   1列目だけ4行あって、2列目が3行しかない…ということはできません。
2. **マス（セル）を直接書き換えない！**:
   表の1マスだけを消したり書き換えたりせず、新しく綺麗な列を作り直す（関数型の安心設計）のが Racket のルールです。

#### 3.6 欠損値 `RFNoData`（空欄データ）の自動スキップ

実際のデータには、データが抜け落ちている「空欄（欠損値）」が含まれることがあります。RacketFrames では空欄のことを **`RFNoData`（アールエフ・ノーデータ）** と呼びます。

```text
  【データの中に空欄があるとき】

   Index   選手名   全国勝率 (NSeries)
    [0]    峰竜太    0.85   --------> 計算に使う
    [1]    毒島誠   [空欄]  --------> 自動的にスキップ！（無視してエラーを防ぐ）
    [2]    瓜生正義  0.72   --------> 計算に使う
```

RacketFrames は、平均値などを計算するときに **空欄の行を自動的にスキップ** してくれるので、途中でプログラムが止まることなく安全に集計できます！

#### 3.7 【深掘り考察】RacketFrames の設計思想をまとめてみよう

最後に、ここまでの仕組みを 5 つのポイントで振り返りましょう。

```text
  +-------------------------------------------------------------------------+
  |              RacketFrames が初心者に優しい 5つの理由                    |
  +-------------------------------------------------------------------------+
  | 1. シンプルな文法 : Python/Rの複雑な文法に迷わず、表操作に集中できる    |
  | 2. Index の安心感 : データの順番がずれても、自動で正しくマッチング      |
  | 3. 計算の自動整列 : 2つの列を足し算するときも、番号を自動で揃えてくれる  |
  | 4. 外部連携が簡単 : CSV, JSON, データベースからそのまま読み込める       |
  | 5. エラーに強い   : 空欄データ (RFNoData) があっても自動でスキップ      |
  +-------------------------------------------------------------------------+
```

##### 1. なぜ Python や R より初心者に最適なのか？
Python の Pandas や R は多機能ですが、文法が複雑で初心者には難解です。RacketFrames は Scratch からステップアップしたばかりの読者でも、直感的な関数だけで表計算ができるように設計されています。

##### 2. なぜ Index が不可欠なのか？
Index はデータの「住所」です。住所があるからこそ、データの順番が入れ替わっても、行と行のつながりが崩れません。

##### 3. 外部データとの連携
CSV ファイルだけでなく、Web の JSON やデータベース（SQLite）から読み込んだデータも、すべてこの「データフレーム」の形に変換して一括処理できます。

#### 3.8 実践：綺麗なデータを抽出してみよう！

それでは、学んだ仕組みを使って、必要な列だけを抜き出してみましょう。

```racket
#lang racket
(require racketframes)

;; 1. CSVファイルを読み込む
(define df (read-csv "data/races.csv"))

;; 2. "racer_name", "win_rate", "rank" の3列だけを安全に抜き出す (df-project)
(define df-clean (df-project df '("racer_name" "win_rate" "rank")))

;; 3. 空欄がある行を除去する (df-drop-na)
(define df-final (df-drop-na df-clean))

;; 4. 結果を画面に表示
(df-summary df-final)
```

アスキーアートと図表のおかげで、RacketFrames の仕組みがとても直感的に理解できるようになりました！
