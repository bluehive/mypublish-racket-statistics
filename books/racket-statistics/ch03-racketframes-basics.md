> **この章のゴール**  
> RacketFrames の基本コンポーネント（DataFrame, Series, Index）を理解し、CSV データを読み込んで必要な列の抽出やデータクレンジングができるようになる。  
> **使用ライブラリ**: `racketframes`  

第2章で手に入れたボートレースの CSV データを、Python の Pandas や R と同じような表形式のオブジェクト **`DataFrame`** として読み込み、自由に扱う方法を学びます。

#### 3.1 RacketFramesの導入：CSVから `DataFrame` へのデータ読み込み

まず、Racket で RacketFrames ライブラリを読み込み、CSV ファイルを読み込んでみましょう。

```racket
#lang racket
(require racketframes)

;; CSVファイルからデータフレームを作成する
(define df (read-csv "data/races.csv"))

;; データフレームの概要を表示する
(df-summary df)
```

`read-csv` 関数を使うだけで、CSV ファイルの1行目をヘッダー（列名）として自動認識し、表データ `DataFrame` が生成されます。
`df-summary` を実行すると、行数、列数、各列のデータ型が一覧表示されます。

#### 3.2 主要コンポーネント：インデックス（Index）とシリーズ（Series）の役割

RacketFrames は、大きく分けて以下の 3 つの構造要素で成り立っています。

```text
+--------------------------------------------------------+
|                      DataFrame                         |
| +----------------------------------------------------+ |
| | Index: [0, 1, 2, 3, 4, 5, ...]                     | |
| +----------------------------------------------------+ |
| | Series: "racer_name" (CSeries: "峰", "毒島", ...)  | |
| | Series: "win_rate"   (NSeries: 0.85, 0.81, ...)    | |
| | Series: "boat_num"   (ISeries: 1, 2, 3, ...)       | |
| +----------------------------------------------------+ |
+--------------------------------------------------------+
```

1. **シリーズ (Series)**:
   データフレームの「1つの列」にあたる1次元配列です。RacketFrames ではパフォーマンスと型安全性を高めるため、データ型に応じたシリーズが用意されています。
   * **`ISeries` (Integer Series)**: 艇番や登録番号などの整数型データ。
   * **`NSeries` (Number/Float Series)**: 勝率や連対率などの実数型データ。
   * **`CSeries` (Categorical/Symbol Series)**: レーサー名や会場名などの文字列・シンボルデータ。
2. **インデックス (Index)**:
   各行を識別するためのラベル（行番号やID）です。高速なデータ検索（定数時間アクセス）を可能にします。
3. **データフレーム (DataFrame)**:
   同じインデックスを共有する複数のシリーズ（列）を束ねた「2次元の表構造」です。

#### 3.3 データのクレンジング：欠損値（`RFNoData`）の処理と列の削除（Project/Drop）

実際のデータには、分析に不要な列が含まれていたり、データが欠落（欠損）している場合があります。これらを綺麗に整理する作業を**データクレンジング**と呼びます。

##### 1. 不要な列の削除と必要な列の抽出
分析に必要な列だけをピックアップしたい場合は `df-project`、不要な列を削りたい場合は `df-drop` を使います。

```racket
;; "racer_name" と "win_rate" と "rank" の列だけを抽出した新しいデータフレームを作る
(define df-clean (df-project df '("racer_name" "win_rate" "rank")))

;; 不要な列 "motor_rate" を除外する
(define df-sub (df-drop df '("motor_rate")))
```

##### 2. 欠損値（`RFNoData`）の扱い
データの中に空欄（欠損値）がある場合、RacketFrames では **`RFNoData`** という特別な値として読み込まれます。欠損値が含まれる行を安全に除去したり補完したりすることで、後の統計計算でのエラーを防ぎます。

```racket
;; 欠損値を含む行を自動的に除外する
(define df-valid (df-drop-na df-clean))
```

これで、分析に必要な綺麗に整った `DataFrame` が準備できました。次章では、このデータフレームを使って実際の統計集計を行っていきます！
