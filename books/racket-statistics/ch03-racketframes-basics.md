#### 3.1 RacketFrames の基本概念

RacketFrames は、Python の Pandas や R 言語のデータフレームに着想を得て作られた、Racket 言語専用の二次元データ構造ライブラリです。

Lisp/Racket の持つ高い型安全性と関数型プログラミングのパラダイムを維持しながら、メモリ内で大量の表形式データを高速に操作・集計・プロットするためのインフラを提供します。

```racket
#lang racket
(require racketframes)

;; CSVファイルからデータフレームを作成
(define df (read-csv "data/races.csv"))

;; データの概要を表示
(df-summary df)
```

#### 3.2 RacketFrames を構成する3つの主要コンポーネント

RacketFrames は、設計上以下の **3つの階層コンポーネント** が密接に連携して動作しています。

```text
+------------------------------------------------------------------+
|                          DataFrame                               |
| ( struct: DataFrame LabelIndex ([series : (Vectorof Series)]) )  |
|                                                                  |
|  +------------------------------------------------------------+  |
|  |  1. Index (行識別子)                                       |  |
|  |     [ 0,  1,  2,  3,  ... ]  (SIndex / IIndex)              |  |
|  +------------------------------------------------------------+  |
|  |  2. Series (列ベクトル)                                    |  |
|  |     • "boat_num"   : ISeries (Fixnum Vector)               |  |
|  |     • "win_rate"   : NSeries (Flonum Vector)               |  |
|  |     • "racer_name" : CSeries (Categorical/Symbol Vector)   |  |
|  +------------------------------------------------------------+  |
+------------------------------------------------------------------+
```

1. **Index（インデックス）**: 行に対するラベル付けと、高速なデータアクセスを担う構造。
2. **Series（シリーズ）**: 同じデータ型の値を一列に並べたメモリ効率の良い1次元配列。
3. **DataFrame（データフレーム）**: 共通の Index を共有し、複数の Series を束ねた2次元の表構造。

---

#### 3.3 Series（シリーズ）の型と特徴

シリーズは、データフレームの「列」に相当する1次元の配列です。RacketFrames では、メモリ消費を抑えて計算を高速化するため、データ型に応じた専用のシリーズが用意されています。

| シリーズ名 | データ型 | 特徴と用途 |
| :--- | :--- | :--- |
| **`ISeries`** | Integer (Fixnum) | 艇番や登録番号などの整数値。メモリ最適化済み |
| **`NSeries`** | Flonum (Float) | 勝率やタイムなどの実数値。高速な数値演算 |
| **`CSeries`** | Symbol / String | 選手名や会場名などのカテゴリカルデータ |
| **`BSeries`** | Boolean | 条件に合うか（`#t`/`#f`）を示す真偽値 |
| **`GenSeries`** | Any | 任意のデータを保持できる汎用シリーズ |
| **`DateSeries` / `DTSeries`**| Date / Datetime | レース開催日などの日付・時間データ |

#### 3.4 DataFrame（データフレーム）の構造的特徴とアクセスの制限

##### 構造的特徴
データフレームは列指向（Column-oriented）で設計されており、内部的には `(Vectorof Series)` として直列に管理されています。データフレーム内のすべてのシリーズは、**全く同じ長さ** と **単一の Index** を共有することが義務付けられています。

##### データアクセスの制限
* **直接的な書き換えの制限**: 純粋関数型の思想に基づき、特定のマス（セル）を直接破壊的に書き換えることは推奨されません。データ変更は新しいシリーズの生成や `df-extend`（列の追加・置換）で行います。
* **位置アクセス (`iloc`) と ラベルアクセス (`loc`)**:
  * 行番号でアクセスする場合: `iloc`
  * インデックスのラベル名でアクセスする場合: `loc`
* **型とアラインメントの制限**: 長さの異なるシリーズを強制的に結合しようとすると、自動的に `RFNoData`（欠損値）で埋められるか、契約違反（Contract Error）となります。

#### 3.5 Index（インデックス）の役割と性能

##### 性能：$O(1)$ の高速検索
インデックスはハッシュテーブル構造（Key $\rightarrow$ List of Index）を採用しており、指定したキー（行ラベル）に対する要素アクセスを**定数時間 $O(1)$** で実行します。

##### 主要な役割
1. **行の割り出し**: 大規模なデータから、特定のID（例：レースID）を持つ行を一瞬で引き出します。
2. **自動位置合わせ（アラインメント）**: 順序がバラバラな2つのシリーズ同士を計算させる際、インデックスのキーを自動的にマッチングして正しく計算させます。
3. **欠損値（`RFNoData`）の整列**: データが存在しない行を安全にスキップ・管理します。

#### 3.6 実践：データのクレンジングと抽出

```racket
#lang racket
(require racketframes)

(define df (read-csv "data/races.csv"))

;; 不要な列を削除し、必要な列だけを安全に射影 (Project)
(define df-selected (df-project df '("racer_name" "win_rate" "rank")))

;; 欠損値 (RFNoData) を含む不完全な行を除去
(define df-clean (df-drop-na df-selected))

;; 概要の確認
(df-summary df-clean)
```

#### 3.7 【深掘り考察】RacketFramesの設計思想とデータ組織化

RacketFrames の構造をより深く理解するため、5つの視点から設計思想を考察します。

##### 1. Python (Pandas) / R との比較と最適ユーザー
Python の Pandas や R は動的型付けと広範なエコシステムに強みがありますが、プログラミング学習者にとっては記号文法や暗黙の型変換が難所となります。
RacketFrames は **Racket の純粋関数型 paradigm** と **DrRacket の洗練された開発環境** に最適化されており、マクロや強力な契約（Contract）システムと親和性が高いため、教育現場や教育用データ分析環境において最も堅牢で信頼性の高い選択肢となります。

##### 2. Index 生成コストとデータ組織化における不可欠性
Index の生成にはハッシュの計算コストが伴いますが、データ組織化の観点から不可欠です。Index が存在しない単なる配列同士では、行の追加や並べ替えの際に行間の対応関係が壊れてしまいます。Index は「データの同一性」を保持する厳密なアンカーとして機能します。

##### 3. Series 間演算 (`+`, `-`, `*`, `/`) と Index の自動整列（アラインメント）
2つの Series 相互の演算を実行する際、RacketFrames は単に行番号の順に計算するのではなく、**Index のキー同士を照合（自動アラインメント）** します。
順序が入れ替わっているデータ同士であっても、共通する Index キーを見つけ出して正しく演算を行い、最終的に両者の Index 構造を合成した新しい Series/Index を生成します。

##### 4. 外部データソース（CSV, JSON, SQLite）との統合柔軟性
`read-csv` や `read-json` だけでなく、Racket の標準 `db` ライブラリ（SQLite / PostgreSQL 連携）から抽出した結果セットを直ちに RacketFrames の `DataFrame` に変換可能です。これにより、分析結果を GUI アプリや Web API サーバーへシームレスに組み込めます。

##### 5. 欠損値（`null`/`NaN`/`RFNoData`）の統計メソッドにおける自動処理
統計メソッド（`df-mean`, `df-std` など）を実行する際、RacketFrames は明示的に `drop-na` を行わなくても、内部的に `RFNoData` が含まれる要素を安全に自動スキップして計算を行います。これにより、不完全なデータが紛れ込んでも実行時エラーでプログラム全体が停止するリスクを防いでいます。
