> **この章のゴール**  
> 難しい統計用語（平均・標準偏差・フィルタ・Groupby）を日常の例えとテキスト図表（アスキーアート）で楽しく理解し、条件ごとの勝率をステップバイステップで計算できるようになる。  
> **使用関数**: `df-mean`, `df-std`, `df-filter`, `df-groupby`

本章では、「平均値」「ばらつき（標準偏差）」「条件絞り込み」「グループ別集計」の4つの重要テクニックを、図表を交えて超親切に学んでいきます。

#### 4.1 基本統計量：平均（Mean）と標準偏差（StdDev）ってなに？

統計で最もよく使われるのが **「平均値」** と **「標準偏差（ひょうじゅんへんさ）」** です。

```text
  【平均値と標準偏差（ばらつき）の直感イメージ】

      ① ばらつきが小さい (標準偏差が小さい)     ② ばらつきが大きい (標準偏差が大きい)
           |  平均 0.50                              |           |           |
        +--+--+                                   +--+-----------+-----------+--+
        | 0.49| (安定している選手)                |0.35          0.50        0.65|
        | 0.51|                                   | (成績に波がある選手・レース) |
        +-----+                                   +------------------------------+
```

* **平均値 (Mean)**: 全員の数値を足して人数で割った「平らにならした代表の数値」。
* **標準偏差 (Standard Deviation)**: 数値が平均値の周りにどれくらい「散らばっているか（ばらつき）」を表す数字。
  * 数字が **小さい** $\rightarrow$ いつも安定して同じ成績を取る。
  * 数字が **大きい** $\rightarrow$ 1着を取ることもあれば6着に沈むこともある「調子に波がある」状態。

RacketFrames なら、たったの1行で計算できます。

```racket
#lang racket
(require racketframes)

(define df (read-csv "data/races.csv"))

;; 1. 全レーサーの平均勝率を求める
(define avg-win-rate (df-mean df "win_rate"))
(printf "全体平均勝率: ~a\n" avg-win-rate)

;; 2. 勝率のばらつき（標準偏差）を求める
(define std-win-rate (df-std df "win_rate"))
(printf "勝率のばらつき: ~a\n" std-win-rate)
```

#### 4.2 データの抽出 (`df-filter`)：条件に合うデータだけを通す「フルイ」

「1号艇のデータだけを見たい！」「A1級のトップ選手だけを集めたい！」というときは、**`df-filter`（データ・フィルター）** を使います。

```text
  【df-filter は条件に合うデータだけを通す「フルイ（ざる）」】

     [全データ (1〜6号艇)] ───> ( 条件: 1号艇のみ？ ) ───> YES ───> [1号艇専用データ]
                                     │
                                    NO (外枠は取り除く)
```

##### 例1: 「1号艇（インコース）」のデータだけを取り出す
> **💡 【実践の視点】なぜ真っ先にインコース（1号艇）のデータを抽出するのか？**  
> ボートレースでは、1号艇（インコース）の1着率が全国平均で約 50〜60% 以上と突出して高いため、舟券予想やデータ分析において **「1号艇を基準（ベースライン）にする」** のが鉄則だからです。まずは 1号艇のデータを抽出して平均着順を出すことで、「この会場や気象条件ではインコースがどれくらい強いのか」を把握し、他の2〜6号艇が逆転する穴展開を予想するための比較基準とします。

```racket
;; boat_num が 1 の行だけを残す
(define df-course1 (df-filter df (lambda (row) (= (hash-ref row "boat_num") 1))))

;; 1号艇の平均着順を計算する
(df-mean df-course1 "rank")  ; => 1.85着など、すごく良い数字が出る！
```

##### 例2: 「勝率 0.75 以上」のエリート選手だけを取り出す
> **💡 【解説】なぜ「0.75（勝率7.50相当）」がエリート基準なのか？**  
> ボートレースの勝率は通常 0.00〜10.00（本書のデータフレームでは 0.00〜1.00 の割合スケール）で計算されます。全プロレーサー約1,600名の中で、勝率 7.50（0.75）以上を維持できるのは **上位わずか数パーセントの最高峰（SG・GIレース常連のトップA1級）** だけです。データから一般選手を除外し、この「勝率0.75以上のエリート枠」に絞り込むことで、トップ選手が外枠に入った時の逆転率などを精度高く分析できます。

```racket
(define df-top-racers
  (df-filter df (lambda (row)
                  (>= (hash-ref row "win_rate") 0.75))))
```

#### 4.3 実践で超よく使われる！「フルイ抽出と計算」の代表事例 5選

現場のデータ分析や舟券予想で頻繁に使われる、**実用的なフルイ（`df-filter`）と計算の組み合わせ事例** を 5つ紹介します。

```text
  【分析現場でよく使われる 5つのフルイパターン】

    ① イン鉄板条件  : 1号艇 × A1エリート選手 ───> 1着確率の算出
    ② 超強力モーター: モーター2連対率 40%以上 ───> 機力による底上げ検証
    ③ アウトコース穴: 5・6号艇の外枠データ    ───> 高配当パターンの抽出
    ④ 会場別限定    : "平和島" など特定会場  ───> 地域特性・荒れやすさの比較
    ⑤ 欠損値クリア  : データ空欄の除外        ───> 確実なデータのみで集計
```

##### 事例1: 「1号艇（インコース）かつ A1級トップ選手」の鉄板レース分析
1号艇にトップ級の選手が入ったレースは「本命（鉄板）」と呼ばれます。この条件に絞って平均着順を求めます。

```racket
;; 1号艇 かつ 勝率 0.75 以上のトップ選手を抽出
(define df-solid-in
  (df-filter df (lambda (row)
                  (and (= (hash-ref row "boat_num") 1)
                       (>= (hash-ref row "win_rate") 0.75)))))

(df-mean df-solid-in "rank")  ; => 平均1.2着など、驚異的な本命データが得られる！
```

##### 事例2: 「超強力モーター（2連対率 40%以上）」を引いた選手の逆転劇分析
ボートレースでは抽選で割り振られるモーターの性能が大きく影響します。「エース機（40%以上）」を引いた艇だけを抽出します。

```racket
;; モーター2連対率が 0.40 (40%) 以上の艇を抽出
(define df-ace-motor
  (df-filter df (lambda (row) (>= (hash-ref row "motor_rate") 0.40))))

(df-mean df-ace-motor "rank")  ; => モーターの良さが着順をどれだけ引き上げるか検証
```

##### 事例3: 「アウトコース（5号艇・6号艇）」に限定した穴展開の分析
不利とされる外枠（5・6号艇）のデータだけをすくい取り、高配当が狙える「穴パターン」を分析します。

```racket
;; 5号艇 または 6号艇 のデータを抽出
(define df-out-course
  (df-filter df (lambda (row) (>= (hash-ref row "boat_num") 5))))

(df-mean df-out-course "win_rate")  ; 外枠に入った選手の平均勝率を算出
```

##### 事例4: 「特定の荒れやすい会場（例: 平和島）」に絞った比較分析
インコースが弱く波乱が起きやすい「平和島」など、特定会場のデータだけをフルイにかけます。

```racket
;; 会場名が "平和島" のデータだけを抽出
(define df-heiwajima
  (df-filter df (lambda (row) (string=? (hash-ref row "stadium") "平和島"))))

(df-groupby df-heiwajima "boat_num" '(("rank" . mean)))  ; 平和島の枠番別平均着順
```

##### 事例5: 「データに空欄（欠損値）がない確実なレース」の厳選集計
フライング（F）などで一部データが欠けている行を除外し、完全に揃った信頼できるデータのみで集計します。

```racket
;; 欠損値 (RFNoData) を含む不完全な行を自動除去
(define df-valid-races (df-drop-na df))

(df-mean df-valid-races "win_rate")  ; 完全データのみで正確な平均値を計算
```

#### 4.4 グループ化と集約 (`df-groupby`)：箱分けして一括集計

データ分析の中で一番パワフルなのが **`df-groupby`（グループバイ）** です。
データを枠番（1枠〜6枠）ごとに「箱分け」して、それぞれの箱の中で平均値を一発で計算してくれます。

```text
  【df-groupby はデータを箱分けして一斉に集計する】

                        ┌───> [1号艇の箱] ───> 平均着順: 1.85着
                        │
    [全データ] ──Groupby──┼───> [2号艇の箱] ───> 平均着順: 2.80着
   (boat_numで分類)     │
                        ├───> [3号艇の箱] ───> 平均着順: 3.40着 ...
                        │     ...
                        └───> [6号艇の箱] ───> 平均着順: 4.85着
```

```racket
;; boat_num (枠番) ごとにグループ化し、着順(rank) と 勝率(win_rate) の平均を集計
(define df-boat-summary
  (df-groupby df "boat_num"
              '(("rank" . mean)
                ("win_rate" . mean))))

;; 集計結果をきれいに表示
(df-show df-boat-summary)
```

実行結果のイメージ：

| boat_num (枠番) | rank_mean (平均着順) | win_rate_mean (平均勝率) |
| :--- | :--- | :--- |
| **1** | **1.85** | **0.68** |
| **2** | **2.80** | **0.55** |
| **3** | **3.40** | **0.50** |
| **4** | **3.85** | **0.46** |
| **5** | **4.20** | **0.42** |
| **6** | **4.85** | **0.38** |

この結果を見ると、**「1号艇がダントツで有利で、外枠に行くほど平均着順が悪くなる」** というボートレースの重要な特徴が、数値としてはっきり証明されます！

---

#### 4.5 まとめと次のステップ

* **平均値 (`df-mean`)**: 全体の代表となる数字。
* **標準偏差 (`df-std`)**: 成績のばらつき（波の大きさ）。
* **フィルター (`df-filter`)**: 条件ごとの実践的フルイ（鉄板・超強力モーター・アウトコース・会場限定・欠損値除去）。
* **グループバイ (`df-groupby`)**: 箱分けして枠番ごとの平均を一発集計。
