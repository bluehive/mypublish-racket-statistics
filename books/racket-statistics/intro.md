> **この章のゴール**  
> データ解析に Racket（および RacketFrames）を選ぶ理由を理解し、DrRacket で基本の式を実行できる状態になる。  
> **想定読者**: Scratch を少し触った経験がある文系大学2年生（プログラミング・統計の初心者）  
> **言語環境**: Racket（`#lang racket`）/ DrRacket  

#### 0.1 統計を学ぶ楽しさとボートレースという題材

統計学やデータサイエンスと聞くと、難解な数式やギリシャ文字が並ぶ教科書を想像して身構えてしまうかもしれません。しかし、統計の本当の面白さは**「手元にあるデータから、まだ誰も気づいていない傾向やルールを掘り起こす探偵のような体験」**にあります。

本書では、その最高の題材として**「ボートレース（競艇）」のデータ**を扱います。
ボートレースは、6艇のボートが1周600mのコースを3周して着順を競う競技です。一見するとシンプルな競技ですが、そこには以下のような多様なデータが存在します。

* **コース（枠番）の有利不利**: 「1コースが圧倒的に強い」とされるが、会場（全国24場）や風向き・波の高さでどう変わるか？
* **レーサーの成績**: 全国勝率、現地勝率、平均スタートタイミング（ST）。
* **モーターの性能**: レースごとに抽選で割り振られるモーターの複勝率（連対率）。

これらのデータをプログラミングを使って集計・分析し、「どのデータがレースの勝敗に最も影響を与えているか」を解き明かしていくプロセスを通じて、統計学の実利を楽しく学びます。

#### 0.2 R/Pythonに匹敵するRacketのデータ解析力：「RacketFrames」の紹介

データ分析といえば、Python（Pandas）や R 言語が有名です。しかし、プログラミング初心者にとって、Python や R の環境構築や独特な文法ルール（複雑なインデントや様々な記号の使い分け）は、データ分析の本質にたどり着く前の大きな壁になります。

本書で採用する **Racket** は、教育用として洗練された非常に美しい言語です。
文法がシンプルで一貫しており、環境構築も「DrRacket」というソフトを1つインストールするだけで完了します。

「でも、RacketでPythonのような本格的な表計算ができるの？」と疑問に思うかもしれません。
安心してください。本書では、PythonのPandasやRのデータフレームに匹敵する強力なデータ解析ライブラリ **「RacketFrames」** を導入します。

```racket
#lang racket
(require racketframes)

;; CSVファイルを1行でデータフレーム（表データ）として読み込む
(define df (read-csv "races.csv"))

;; 会場ごとにグループ化して平均勝率を一発で集計する
(df-groupby df "stadium" '(("win_rate" . mean)))
```

このように、複雑なプログラムを書くことなく、**わずか数行の直感的なコードで大量のレースデータを自由自在に操作・集計**できるようになります。

#### 0.3 DrRacket のインストールと最初の準備

まずは、開発環境である **DrRacket** を準備しましょう。

1. [Racket 公式サイト](https://download.racket-lang.org/) にアクセスし、お使いのOS（Windows / Mac / Linux）に合ったインストーラをダウンロードして実行します。
2. インストールが完了したら、**DrRacket** を起動します。
3. 画面は上下（または左右）の2つのエリアに分かれています。
   * **定義ウィンドウ（上のエリア）**: プログラムコードを書き保存する場所。
   * **相互作用ウィンドウ（下のエリア / REPL）**: 式を入力すると、その場で計算結果が返ってくる対話画面。
4. ファイルの先頭に、使用する言語を指定するおまじないを書きます。

```racket
#lang racket
```

画面上部の **「Run」** ボタン（または Ctrl+R / Cmd+R）を押すと、プログラムが読み込まれます。

#### 0.4 式と評価規則：Racket のシンプルな文法

Scratch では「(10) + (20)」のようなブロックを組み立てました。Racket での計算も全く同じです。
Racket のコードは、すべて **` (演算子 引数1 引数2 ...) `** という統一された形で書きます。

```racket
#lang racket

(+ 10 20)      ; => 30
(* 5 8)        ; => 40
(- 100 35)     ; => 65
(/ 50 2)       ; => 25
```

* **開き括弧 `(` の直後には、必ず行いたい計算（演算子や関数名）** を書きます。
* 値と値の区切りは**スペース**で行います（カンマ `,` は使いません）。
* コメント（プログラムとして実行されないメモ）は半角セミコロン `;` から始めます。

複数の計算を組み合わせる「ネスト（入れ子）」も簡単です。

```racket
;; 3 と 4 を掛けた結果に、10 を足す
(+ 10 (* 3 4))  ; => 10 + 12 = 22
```

計算は、最も内側の括弧 `(* 3 4)` から順番に評価されていきます。

#### 0.5 本書で構築するシステム：ボートレース統計と簡易予測モデル

本書を読み進めることで、以下のステップを追って学習を進めていきます。

1. **データ収集（第2章）**: Web上のボートレースデータ（出走表やレース結果）の構造を理解し、手元に読み込む。
2. **前処理（第3章）**: RacketFrames を使って、欠損値（空欄）の処理や不要なデータの除去（クレンジング）を行う。
3. **基礎統計・集計（第4章）**: 平均・分散・標準偏差の計算や、枠番別・コース別の勝率集計を行う。
4. **可視化（第5章）**: 散布図やヒストグラムを描画し、データ間の相関（例：レーサーの体重と勝率の関係）を直感的に捉える。
5. **予測モデル作成（第6章）**: 過去の統計データをもとに、未来のレース結果を予測するスコアモデルを作成・検証する。

#### 0.6 本書の進め方

プログラムを書いていて動かなくなったときのために、付録Cには「DrRacket のデバッグ方法とお助け機能」を用意しています。また、各章の終わりには「※三角ロジックで整理予定」として、得られたデータの事実（Data）、そこから言える主張（Claim）、その橋渡しとなる論拠（Warrant）を整理する思考ノートの枠組みを用意しています。

それでは、Racket と RacketFrames を使った楽しいデータサイエンスの世界へ踏み出しましょう！
