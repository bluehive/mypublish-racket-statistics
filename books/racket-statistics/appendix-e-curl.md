#### E.1 `curl`（カール）とは？

**`curl`（Client URL / カール）** は、インターネット上のサーバーと通信し、データのダウンロードやアップロードをターミナル（コマンドライン）から行うための世界標準のデータ収集ツールです。

ウェブブラウザ（Chrome や Edge）が「マウスでページを表示するツール」だとすれば、`curl` は **「プログラムやコマンドから直接データを手元に引き寄せるツール」** です。

```text
  【ウェブブラウザ vs curl コマンドのイメージ】

   [ウェブブラウザ] ──> マウスで画面を見る (人間用)
   [curl コマンド]  ──> ターミナルから一瞬でファイルを保存 (データ分析・プログラム用)
```

---

#### E.2 OS 別の `curl` インストール方法

`curl` は多くの OS（macOS や Windows 10/11）に最初から標準搭載されていますが、インストールされていない場合のセットアップ手順は以下のとおりです。

##### 1. Linux (Ubuntu / Debian / Linux Mint)
ターミナルで以下の 2 行を実行します。

```bash
sudo apt update
sudo apt install -y curl
```

##### 2. macOS
macOS には最初から `curl` が組み込まれています。特別なインストール作業は不要です。

##### 3. Windows (Windows 10 / 11)
Windows 10（1803以降）および Windows 11 の「コマンドプロンプト」または「PowerShell」には、標準で `curl.exe` が入っています。ターミナルを開いて `curl --version` と打つだけでそのまま利用できます。

> **⚠️ 注意**  
> `curl` のインストールは OS のシステム管理者権限（`sudo` や `apt`）を伴うため、本書の `mise.toml` タスクランナーには含めていません。お使いの OS のパッケージマネージャーを使って直接セットアップしてください。

#### E.3 基本的な `curl` コマンドスクリプト一覧

よく使われる `curl` の代表的なコマンドパターンを紹介します。

```text
  +-----------------------------------------------------------------------------------+
  |               🛠️ よく使う `curl` コマンドの代表パターン一覧                      |
  +-----------------------------------------------------------------------------------+
  | ① curl URL                     : Web ページの内容を画面にそのまま表示する          |
  | ② curl -o filename URL         : 指定したファイル名で保存する                     |
  | ③ curl -O URL                  : サーバー上のファイル名と同じ名前で保存する        |
  | ④ curl -s -o filename URL      : 進捗メーターを出さずに静かに保存する (Silent)    |
  | ⑤ curl -s -L -o filename URL   : 転送先 (リダイレクト) を追跡して保存する         |
  +-----------------------------------------------------------------------------------+
```

##### ① 画面に表示する
```bash
curl https://example.com
```

##### ② ファイルとして保存する (`-o`)
```bash
curl -o sample.html https://example.com
```

#### E.4 本書で使うボートレースデータダウンロード・スクリプトの徹底解説

本書（第2章〜第6章）の実習で使用した 2 種類のボートレースデータダウンロードスクリプトについて、オプションの意味を詳しく解説します。

##### 1. 公式サンプルデータ (CSV) のダウンロード
```bash
curl -s -o data/sample_races.csv "https://raw.githubusercontent.com/bluehive/mypublish-racket-statistics/main/data/sample_races.csv"
```

##### 2. ボートレース公式Webサイトの出走表 (HTML) ダウンロード
```bash
curl -s -o data/raw/racelist_sample.html "https://www.boatrace.jp/owpc/pc/race/racelist?rno=1&jcd=01&hd=20260725"
```

##### 💡 コマンドのオプション解説
* **`-s` (Silent / 静か)**:
  ダウンロード中の進捗メーター（「10%... 50%...」などのプログレスバー）をターミナルに出力せず、静かにバックグラウンドで処理を行います。
* **`-o` (Output / 保存先の指定)**:
  取得したデータをどのフォルダ・ファイル名で保存するかを指定します（例: `data/sample_races.csv`）。指定したフォルダが存在しないとエラーになるため、事前またはスクリプト内で `mkdir -p data` を実行しておきます。
* **`"URL"` (ダブルクォーテーションで囲む理由)**:
  URL に含まれる `?` や `&` などの記号（例: `?rno=1&jcd=01`）が、シェル（Bash）の特殊命令として誤作動するのを防ぐため、必ずダブルクォーテーション `""` で囲みます。

---

#### E.5 まとめ

`curl` は、Web からデータを自動収集して分析のパイプラインに流し込むための「起点」となる最も信頼できるツールです。
各オプション（`-s` や `-o`）の意味を理解すれば、どんな Web サイトやオープンデータも自由自在にターミナルから取得できるようになります！
