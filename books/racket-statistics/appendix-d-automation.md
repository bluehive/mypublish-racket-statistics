> **この付録のゴール**  
> 読者・学習者が複雑なコマンドやスクリプトを覚えることなく、開発タスクランナー `mise` を使ってサンプルデータのダウンロード、最推しプロット表示、予想AI答え合わせテストを「ワンコマンド」で一発実行できるようになる。  

---

#### D.1 タスクランナー `mise` とは？（読者のためのお助け魔法）

データ分析を行っていると、長いコマンドを入力したり、ファイルパスを指定してプログラムを動かしたりする作業が少し面倒に感じることがあります。

**`mise`（ミズ）** は、そうした面倒なコマンドをたった1行のショートカット（例: `mise run plot:scatter`）で瞬時に呼び出せる **「学習者のためのお助け魔法ツール」** です。

```text
  【mise があれば、面倒なコマンド入力を一発ショートカット！】

   [手動での入力] ──> racket code/ch05-visualization.rkt  (長くて打ち間違いやすい...)
                                 ||
                                 \/
   [mise の世界]  ──> mise run plot:scatter             (たった1行で一発プロット起動！)
```

---

#### D.2 読者・学習者のためのワンコマンドタスク一覧

本書のプロジェクト（`mise.toml`）には、第4章〜第6章の「大盛り」で学んだ分析をワンタッチで動かす以下の便利コマンドが用意されています。

```text
  +-----------------------------------------------------------------------------------+
  |               🚀 読者のための `mise run` ワンコマンドマップ                       |
  +-----------------------------------------------------------------------------------+
  | ① mise run data:download   : 公式サンプルデータ (CSV) を一瞬でダウンロード      |
  | ② mise run analysis:summary: 1号艇有利のデータ集計を一発で計算                    |
  | ③ mise run plot:scatter    : 【第5章最推し】モーター vs 着順の散布図を一発プロット  |
  | ④ mise run model:predict   : 【第6章クライマックス】予想AI答え合わせテストを一括実行|
  | ⑤ mise run book:preview    : 本書の原稿をブラウザで綺麗にローカル表示             |
  +-----------------------------------------------------------------------------------+
```

---

#### D.3 各自動化タスクの詳しい使い方

##### 1. 公式サンプルデータが一瞬で手に入る！
```bash
mise run data:download
```
分析に必要なボートレースの公式サンプルデータ（`sample_races.csv`）を、Web から手元の `data/` フォルダへ自動で安全にダウンロード・配置します。

##### 2. 1号艇の勝率集計を一括実行！
```bash
mise run analysis:summary
```
第4章で学んだ枠番ごとの平均着順（1号艇=1.85着など）や平均勝率の集計プログラムをターミナルから一発で動かします。

##### 3. 🔥【最推し】散布図プロットが一瞬で画面に飛び出す！
```bash
mise run plot:scatter
```
第5章の最推し（オススメ）グラフである **「モーター2連対率 vs 確定着順」の散布図プロット** を一発で画面に描画します！コマンドを1行打つだけで、機力の恩恵を示す右下がりの美しい点群が画面に表れます。

```text
  【mise run plot:scatter を実行したときのイメージ】

   $ mise run plot:scatter
   [plot:scatter] $ racket code/ch05-visualization.rkt
   👀 プロットウィンドウが自動起動！ (モーター2連対率 vs 着順の散布図がポップアップ表示)
```

##### 4. 🔥【クライマックス】予想AIモデルの答え合わせテストを一括実行！
```bash
mise run model:predict
```
第6章で構築した「予想スコアモデル」を自動で走らせ、過去レースデータでの **1着的中率の答え合わせテスト** をワンコマンドで実行します！

```text
   $ mise run model:predict
   検証したレース数: 100
   1着的中数: 58
   予測的中率: 58.0%  <-- 答え合わせ結果が一瞬で画面に表示！
```

##### 5. 本書の原稿を自分のPCで綺麗にプレビュー表示！
```bash
mise run book:preview
```
Zenn CLI のプレビューサーバーが起動し、ブラウザ（`http://localhost:8000`）で執筆中の章をリアルタイムに読むことができます。

---

#### D.4 まとめ

`mise` を使えば、複雑なファイル構造やコマンドを意識することなく、ワンコマンドで快適にデータ分析の実習を進めることができます。
ぜひターミナルで `mise run plot:scatter` や `mise run model:predict` を叩いて、一瞬で動く感動を体験してみてください！
