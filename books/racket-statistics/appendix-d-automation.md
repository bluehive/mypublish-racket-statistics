#### D.1 タスクランナー `mise` とは？（推奨メッセージ）

**`mise`（ミズ / 旧rtx）** は、Node.js や Racket といった開発ツールのバージョン管理と、プロジェクトごとのコマンド実行（タスクランナー）を1つに統合した新世代の強力な CLI ツールです。

> **💡 【著者からの推奨メッセージ】**  
> `mise` は **必ずしもインストールしなくても（ターミnal で直接 `racket code/ch05-visualization.rkt` のように手動でコマンドを入力するだけでも）、本書の学習を問題なく最後まで進めることができます**。  
> しかし、`mise` を導入すると、長くて覚えにくいコマンドを `mise run plot:scatter` のように一発のショートカットで動かせるようになり、開発効率が劇的に向上します。現代のソフトウェア開発の現場でも広く使われている優れたツールですので、**ぜひこの機会にインストールして覚えておくことを強く推奨（オススメ）します！**

```text
  【手動コマンド入力 vs mise ショートカットの比較】

   [手動入力 (手作業)] ──> racket code/ch05-visualization.rkt  (長くて打ち間違いやすい)
                                 ||
                                 \/
   [mise の世界]      ──> mise run plot:scatter             (たった1行でプロット一発起動！)
```

#### D.2 `mise` のインストールとシェルの初期設定

`mise` は、お使いの OS に応じて簡単なコマンドで数秒でインストールできます。

##### 1. インストール手順 (Linux / macOS)

**【スタンドアロン・スクリプト（最も簡単・推奨）】**
ターミナルを開き、以下の 1 行のコマンドを実行します。

```bash
curl https://mise.run | sh
```

**【Homebrew をお使いの場合 (macOS)】**
```bash
brew install mise
```

##### 2. シェルへのアクティベート（自動読み込み設定）

`mise` コマンドを常にターミナルで使えるようにするため、お使いのシェル設定ファイル（`~/.bashrc` や `~/.zshrc`）の末尾にアクティベート設定を追加します。

```bash
# Bash をお使いの場合
echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc
source ~/.bashrc

# Zsh をお使いの場合 (macOS標準)
echo 'eval "$(~/.local/bin/mise activate zsh)"' >> ~/.zshrc
source ~/.zshrc
```

これで `mise --version` と入力してバージョンが表示されれば、インストールの完了です！

#### D.3 プロジェクトでの初期設定：`mise trust` と `mise install`

`mise` が導入されたリポジトリ（`mise.toml` が含まれるディレクトリ）へ初めて入ったとき、**安全のために行うべき 2 つの重要なセットアップコマンド** があります。

```text
  【プロジェクトディレクトリに入った時の 2 ステップ】

   [リポジトリ移動] ───> ① mise trust   (セキュリティ保護のため設定ファイルを「信頼」する)
                       │
                       └──> ② mise install (プロジェクトで必要なツールを一括セットアップ)
```

##### ① `mise trust` （設定ファイルの信頼許可）
誰かが作った `mise.toml` に悪意のあるスクリプトが含まれていないか保護するため、初回アクセス時には信頼の確認が求められます。以下のコマンドを実行して信頼を許可します。

```bash
mise trust
```

##### ② `mise install` （依存ツールの自動一括セットアップ）
`mise.toml` に記述された言語環境や開発ツールを一発でプロジェクト内に自動セットアップします。

```bash
mise install
```

#### D.4 本書で使えるワンコマンドタスク一覧

初期設定が完了したら、プロジェクト内で以下の `mise run ...` コマンドを打つだけで、第4章〜第6章の大盛りで学んだデータ分析やプロットが一発で起動します！

```text
  +-----------------------------------------------------------------------------------+
  |               🚀 読者のための `mise run` ワンコマンドマップ                       |
  +-----------------------------------------------------------------------------------+
  | ① mise run data:download          : 公式サンプルデータ (CSV) を一瞬でダウンロード |
  | ② mise run data:download:official : 【pyjpboatrace流】公式Webの出走表HTMLを取得   |
  | ③ mise run analysis:summary       : 1号艇有利のデータ集計を一発で計算             |
  | ④ mise run plot:scatter           : 【第5章最推し】モーター vs 着順の散布図プロット |
  | ⑤ mise run model:predict          : 【第6章クライマックス】予想AI答え合わせテスト  |
  | ⑥ mise run book:preview           : 本書の原稿をブラウザで綺麗にローカル表示      |
  +-----------------------------------------------------------------------------------+
```

##### 実行例: 散布図プロットの一発表示
```bash
mise run plot:scatter
```

```text
   $ mise run plot:scatter
   [plot:scatter] $ racket code/ch05-visualization.rkt
   👀 プロットウィンドウが自動起動！ (モーター2連対率 vs 着順の散布図がポップアップ表示)
```

#### D.5 まとめ

* **手動でもOK、でも `mise` は超オススメ！**: コマンド手入力でも学習可能ですが、`mise` を使うとデータ分析の開発体験が劇的に快適になります。
* **初期設定は2ステップ**: リポジトリに入ったら `mise trust` と `mise install` を実行しましょう。
* **ワンコマンドで感動体験**: `mise run plot:scatter` や `mise run model:predict` を叩いて、一瞬で動く快感をぜひ楽しんでください！
